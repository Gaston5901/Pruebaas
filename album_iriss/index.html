¿Cómo funciona?

  • 🔒 Clave: para abrir el diario, poné la fecha en que empezamos a hablar.
  • ＋ (botón rosa): crea una hoja nueva con fecha, foto y texto.
  • ✏️: edita una hoja cuando quieras.
  • 🗑️: borra una hoja (te pide confirmación antes).
  • 📷: podés sumar una foto del día; se achica sola para no pesar.
  • 🎨 Colorear: en el editor, seleccioná unas palabras y dales color o un estilo de letra distinto.
  • 📖 Leer todo: abre la hoja completa cuando el texto es largo.
  • Ant. / Sig. / Última ⏭: para moverte entre las hojas.
  • ✕: cierra el diario. ← (arriba a la izquierda) vuelve al inicio.
  • 💾: todo se guarda solito en este dispositivo, sin internet.
