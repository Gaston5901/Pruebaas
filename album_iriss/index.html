Ayuda del diario

Acá tenés una guía rápida para usar todos los botones y personalizar tus páginas.

  • 🔒 Clave: mové las tres ruedas de día, mes y año hasta formar la fecha correcta y tocá “Desbloquear”.
  • ＋ junto al lápiz: te lleva a la hoja final y abre el formulario para crear una página nueva.
  • ✏️: abre el editor para cambiar fecha, título, texto, foto, color o letra.
  • 🗑️: borra una página después de pedirte confirmación.
  • 📷: agrega una foto; se comprime automáticamente para que ocupe menos espacio.
  • 🎨 Colores: seleccioná una palabra o frase y tocá un color. Si no seleccionás nada, el color queda activo para lo que escribas.
  • ✍️ Tipografías: seleccioná texto y elegí un estilo de letra. Sin selección, lo nuevo se escribe con esa tipografía en vivo.
  • 🧽 Quitar formato: devuelve el texto seleccionado a su color y letra normales.
  • 📖 Leer todo: abre la página completa cuando el texto es largo.
  • ←: vuelve a la página anterior; desde la primera entrada regresa a la portada.
  • ⏭: salta directamente a la última página escrita.
  • →: avanza a la siguiente página. La última hoja sirve para crear una nueva.
  • 💾: todo queda guardado automáticamente en este dispositivo, sin internet.
  • ✕: cierra el diario. ← arriba: vuelve al inicio.
